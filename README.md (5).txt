# Task 27 - Reading and Writing Excel Data

## Overview
This task demonstrates how to read, process, and write Excel files using Pandas.

## Topics Covered
- Creating DataFrames and saving data to Excel files
- Reading Excel files using `read_excel()`
- Reading a specific worksheet
- Displaying the first five rows
- Checking dataset information and missing values
- Selecting specific columns
- Filtering and sorting records
- Saving filtered data into a new Excel file
- Reading selected columns
- Adding new records and saving updated datasets

## Tools Used
- Python
- Pandas
- OpenPyXL
- Jupyter Notebook

## Files Included
- `task27_reading_writing_excel.ipynb`
- `employees.xlsx`
- `high_salary_employees.xlsx`
- `updated_employees.xlsx`

## Outcome
Learned how to read, process, filter, and save Excel data using Pandas.
